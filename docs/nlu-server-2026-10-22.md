# ধাপ G — সার্ভার (প্লাগিন ১.১০.০), ২২ অক্টোবর ২০২৬

নতুন ফাইল `tool/wordpress/my-assistant-accounts/nlu.php` (আর spec থেকে বানানো `nlu-intents.php` — `python3 tool/nlu/spec/php_intents.py`)।
শুধু নতুন টেবিল যোগ হয়, পুরনো কোনো টেবিল বদলায় না। পুরনো `/ai` আগের মতোই চলে, তাই পুরনো অ্যাপও চলবে।

## টেবিল
- `ma_nlu_samples` — শেখার নমুনা: পরিচয়হীন লেখা (নাম `<নাম১>`), অবস্থা, ফোনের/ক্লাউডের/শেষ ফল, ভুলের সংকেত (`signal_kind`; MySQL-এ `signal` শব্দটা সংরক্ষিত বলে নাম এটা), সম্মতির সংস্করণ। সদস্যের id নেই, শুধু লবণ-মেশানো hash।
- `ma_nlu_labels` — এডমিনের দেওয়া সঠিক লেবেল।
- `ma_nlu_models` — ফোনের মডেলের সংস্করণ: ঠিকানা (https), SHA-256, সীমা, eval, কত % সদস্য পাবেন, draft/live/retired।
- সেটিংস `ma_nlu_settings` (option): `mode` off/shadow/on, `pct`, ক্লাউড চালু, ফ্রি/প্রো/উঁচু মডেল, Sonnet-এর ভাগ (৫%), সদস্যপ্রতি দৈনিক সীমা (ফ্রি ২০, প্রো ৬০), সম্মতির সংস্করণ।

## সদস্যের এন্ডপয়েন্ট (সেশন টোকেন দিয়ে)
| | কাজ |
|---|---|
| `GET /nlu/config` | mode (সদস্যের স্থির শতাংশ-ঘর ধরে), ক্লাউড চালু কিনা, আজ কত বাকি, live মডেলের সীমা |
| `GET /nlu/model` | এই সদস্যের live মডেল (rollout % ধরে), না থাকলে 204 = অ্যাপের ভেতরেরটাই |
| `POST /nlu/resolve` | ক্লাউডে বোঝা — নিচে |
| `POST /nlu/samples` | একসাথে ≤১০০ নমুনা; সম্মতি না থাকলে 403 |
| `DELETE /nlu/samples/mine` | নিজের সব নমুনা মুছে ফেলা |
| `POST /ai/sources` | এখন ছায়া মোডের গণনাও নেয় (`nlu_same_sure`, `nlu_differ`, …) |

## `/nlu/resolve`
- ফ্রি → Gemini 3.1 Flash-Lite; প্রো → Claude Haiku 5.5; প্রো আর ফোন খুব অনিশ্চিত (< ০.৪) → Sonnet 5.5, দিনের ক্লাউড-পড়ার ৫%-এর মধ্যে। একটা ব্যর্থ হলে অন্যটা; 429/529/503/টাইমআউটে একবার আবার।
- নির্দেশনা ছোট আর শুধু বোঝার জন্য (সংস্করণ `v1`), intent-এর তালিকা spec থেকে; `route` টুল জোর করে ডাকা — Anthropic-এ tool, Gemini-তে function calling। Anthropic-এ স্থির অংশ cache করা।
- ফল যাচাই: spec-এ নেই এমন intent বাদ; মেসেজে নেই এমন শব্দ (যেমন নিজে বানানো সংখ্যা) তথ্য হিসেবে বাদ।
- ফোন নম্বর, লম্বা কোড, পাসওয়ার্ড/পিন/OTP থাকলে 422 — ফোনেই থাকবে।
- খরচ `ma_ai_usage`-এ (মডেল আর প্ল্যান ধরে); বাজেট পেরোলে 503; সব-বন্ধ সুইচ (`ma_ai_on`) বন্ধ করলে 503।
- সম্মতি থাকলে ক্লাউডের ফল নমুনা হিসেবে জমা।
- Gemini-র key: `wp-config.php`-এ `define('MA_GEMINI_API_KEY', '…');` (ভালো), নয়তো option `ma_gemini_key`।

## লোকসান যেন না হয় — বাজেট আয় অনুযায়ী (মালিকের নির্দেশ, ২২ অক্টোবর)
হাতে বাজেট না বসালে নিজে থেকে:
- প্রো: এ মাসে সক্রিয় প্রো সদস্য × মাসিক দাম (মাসিক ৯৯ বা বার্ষিক ৯৯৯÷১২ — যেটা কম) এর **২০%** পর্যন্ত AI-তে; দিনে তার সমান ভাগের দ্বিগুণ পর্যন্ত।
- একজন প্রো সদস্য: মাসে তাঁর দেওয়া টাকার **৩০%** পর্যন্ত (এখন প্রায় $০.২০ = ~৳২৫); এর বেশি হলে সেই মাসে তাঁর ক্লাউড বন্ধ, ফোনে চলে।
- ফ্রি: সবার জন্য মিলিয়ে মাসে $৩, দিনে $০.২০।
- টাকা→ডলার: `ma_usd_bdt` (ধরা ১২২)। সেটিংস পাতায় "আয় অনুযায়ী নিজে ঠিক হোক" টিক তুলে হাতে বাজেট বসানো যায়।
- Gemini key-এর ঘর এখন সেটিংস পাতায় Anthropic key-এর পাশে (অথবা `wp-config.php`-এ `MA_GEMINI_API_KEY`)।

## ধাপ I — শেখার চক্র (প্লাগিন ১.১১.০, অ্যাপ ২.৪০.০)
- **অ্যাপ:** "আরও" পাতায় সম্মতির সুইচ (ডিফল্ট বন্ধ)। চালু থাকলে সব অমিল আর ১০% মিল নমুনা হিসেবে জমে (≤২০০), দিনে একবার ≤১০০ করে যায়। নাম ফোনেই `<নামN>` হয় (লেজার, কন্টাক্ট, মডেলের person ঘর থেকে); গোপন শব্দ, ফোন নম্বর বা ≥৬ অঙ্কের কোড থাকলে নমুনাই হয় না। "না"/আবার বলা = ভুলের সংকেত। "আমার পাঠানো বার্তা মুছে দিন" → `DELETE /nlu/samples/mine`।
- **মডেল বদল:** `GET /nlu/model` থেকে নতুন মডেল নামে, SHA-256 মিললে তবেই রাখে; লোড না হলে মুছে অ্যাপের ভেতরেরটায় ফেরে।
- **সার্ভার:** "নতুন করে শেখানোর key" (সেটিংস পাতা) — শুধু `GET /nlu/ci/export` আর `POST /nlu/ci/model` (শুধু draft)।
- **GitHub:** `nlu_retrain.yml` — `nlu-retrain` শাখায় push বা হাতে চালালে: নমুনা আনা → লেবেল (এডমিন > সদস্যের সংশোধন > ক্লাউড > ফোন ≥০.৯) → ডেটা বানানো → BERT শেখানো → gate (কোনো intent ১ পয়েন্টের বেশি নামলে, মোছা/টাকায় নামলে বা ভুল-মোছা বাড়লে বাতিল) → draft হিসেবে সার্ভারে। চালু করা এডমিন অ্যাপ থেকে হাতে।
- **মালিকের কাজ:** প্লাগিন ১.১১.০ বসানো; key বানিয়ে GitHub secret `MA_NLU_CI_KEY`; সদস্যদের সম্মতি।
- **যাচাই:** Flutter ২,১০২ টেস্ট পাস; WordPress e2e সব পাস। আসল সাইটে আর পুরো retrain চক্র এখনও চালানো হয়নি।
