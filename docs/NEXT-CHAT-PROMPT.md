### Keystore আর পাসওয়ার্ডের নিয়ম (খুব জরুরি)
- keystore কখনো commit করবে না। পাসওয়ার্ড কখনো print করবে না বা log-এ রাখবে না। Google পাসওয়ার্ড কখনো চাইবে না।
- পাসওয়ার্ড ফাইলে একটা লাইন আছে যেখানে শুধু `পাসওয়ার্ড:` লেখা। আসল মান তার **পরের খালি-নয় এমন লাইনে**। আগের একটা বাক্যেও "পাসওয়ার্ড" শব্দটা আছে, সেটা ধরবে না।
- ফাইলটা পড়বে শুধু python দিয়ে, umask 077 দিয়ে বানানো একটা mktemp ফাইলে লিখে। তারপর `KP=$(cat f); shred -u f`, আর শেষে `unset KP`।
- ফাইলের কোনো লাইন কখনো দেখাবে বা preview করবে না।
- সাইনের পর certificate SHA256 মেলাবে: `FC:6C:FF:35:E5:9A:32:E2:6D:A5:…`। না মিললে APK পাঠাবে না।

## কাজের পরিবেশ আর রুটিন

### সেটআপ
- Flutter **3.47.7 stable**। আগের কন্টেইনারে এটা ছিল `/opt/fl/flutter`-এ (`PUB_CACHE=/opt/fl/.pub-cache`)। নতুন কন্টেইনারে না থাকলে ইনস্টল করো, তারপর একবার `flutter pub get` চালাও।
- এরপর সব flutter কমান্ডে `--no-pub` দেবে। `flutter analyze` চালাবে `--no-pub` দিয়ে, নইলে pub get-এ আটকে যায়।
- `android/app/build.gradle.kts` gitignored। এটা `tool/setup_platforms.sh` থেকে তৈরি হয়।
- GitHub-এর GraphQL বন্ধ, REST দিয়ে কাজ করবে (`gh api …`)। স্যান্ডবক্স থেকে release বানানো যায় না, তাই বিল্ড হয় GitHub workflow দিয়ে।
- signer: apksigner-এর uber.jar। আগে ছিল `/opt/apksig/uber.jar`। নতুন কন্টেইনারে না থাকলে Android build-tools-এর `apksigner` বা `uber-apk-signer` নামাও।

3. `git fetch && git rebase origin/next-update && git push origin next-update`
4. বিল্ড চালাও:
   ```bash
   gh workflow run play_preview.yml --ref next-update -R iamsaifsaiful/digital_brain
   gh run list -R iamsaifsaiful/digital_brain --workflow play_preview.yml -L1   # id নাও
   gh run watch <id> -R iamsaifsaiful/digital_brain --exit-status             # ~১৫-২০ মিনিট
   ```
   অ্যাডমিন অ্যাপের জন্য workflow `admin_app.yml`।
5. Asset নামাও:
   - `gh api "repos/iamsaifsaiful/digital_brain/releases?per_page=1"` → `play-preview-arm64.apk` আর `play-preview-armv7.apk`-এর id নাও।
   - তারপর `gh api repos/iamsaifsaiful/digital_brain/releases/assets/<id> -H "Accept: application/octet-stream" > file.apk`
6. অ্যাটাচ করা keystore দিয়ে আবার সাইন করো:
   ```bash
   java -jar uber.jar --apks X.apk --allowResign --ks my-assistant-release.jks --ksAlias "$AL" --ksPass "$KP" --ksKeyPass "$KP" --overwrite
   ```
   - alias নেবে `keytool -list` থেকে, PrivateKeyEntry-টা। আগে এটা ছিল `myassistant`।
   - এরপর `keytool -printcert -jarfile X.apk` দিয়ে SHA256 মেলাও।
   - `.idsig` ফাইলগুলো মুছে দাও।
7. ফাইলের নাম দাও `My-Assistant-Play-Preview-<ver>-b<N>-arm64.apk` আর `…-armv7.apk`। SendUserFile দিয়ে পাঠাও (display "attach")। সাথে কয়েকটা পাতার light/dark স্ক্রিনশটের একটা শিট দাও।
8. ডক আপডেট করো:
   - `docs/HANDOFF.md`-এ নতুন §0h অংশ যোগ করো।
   - `docs/pending-2026-10-22.md` আপডেট করো।
   - Project-এ `claude/digital-brain-<ver>-….md` লেখো।
9. বাংলায় রিপোর্ট দাও: কী বদলেছে, কী সরেছে বা ছোট হয়েছে, কোন টেস্ট পাস করেছে (নিজে চালানো সংখ্যা), আর **কী যাচাই হয়নি**।
