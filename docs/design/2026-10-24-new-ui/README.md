# নতুন UI-এর নকশা (২৪ অক্টোবর ২০২৬)

> **বাতিল (২৪ অক্টোবর সন্ধ্যা):** মালিক হোমের নতুন, চূড়ান্ত নকশা অনুমোদন করেছেন — `docs/design/2026-10-24-home-final/` আর তার `PROMPT.md` দেখুন। এই ফোল্ডার শুধু পাতার তালিকা হিসেবে কাজে লাগবে।

- `img/01-home.jpg … 28-search.jpg` — ২৮টা পাতা, ফোনের মাপে (৭৮০×১৬৮৮)। `overview.jpg` — সব এক পাতায়।
- `html/` — নকশার HTML/CSS (`head.html` = রং, মাপ, ভাগ করা স্টাইল; `bodyN.html` = পাতাগুলো; `mock.html` = পাতা ১–২ পুরো)। আবার ছবি বানাতে পাশে `fonts/` ফোল্ডার লাগবে (`assets/fonts/`-এর Hind Siliguri ও Noto Sans Bengali, Flutter-এর `MaterialIcons-Regular.otf`, Inter)।
- `PROMPT.md` — এই নকশা অ্যাপে বসানোর পুরো নির্দেশ (অন্য অ্যাকাউন্টে Claude-কে দেওয়ার জন্য)।

খোলা সিদ্ধান্ত: নকশা অনুমোদন, হোমের বোতাম (মাইক / +), হাতে লেখা লেখা রাখা, মূল রং — `PROMPT.md` §৩।
