# নতুন UI — যা বানানো হলো (২৪ অক্টোবর ২০২৬, 2.49.0)

মালিকের সিদ্ধান্ত: দরকার হলে নকশা বদলানো যাবে, তবে কোনো কিছু বাদ যাবে না; FAB = 🎤 মাইক;
হাতে লেখা নোট থাকবে, ছোট আর সাজানো; মূল রং গাঢ় সবুজ-কালো, অ্যাকসেন্ট বদলানো যায়;
"প্রো" → "প্রিমিয়াম" সব জায়গায় (ভেতরের id/সার্ভার key বদলায়নি)।

## ভিত্তি
- `lib/ui/theme.dart`: নতুন token (ground/surface/ink/muted/line/chip/soft, primary/fill/fab,
  warn/danger/nowLine/sun); ডিফল্ট অ্যাকসেন্ট `forest`। এই অ্যাকসেন্টে ক্যাটাগরির রং
  (blue/purple/ochre/teal/rose/orange) শান্ত, মাটির রঙে — অন্য অ্যাকসেন্টে আগের মতো।
- `lib/ui/kit.dart`: HandNote (Galada ফন্ট, OFL), HeroCard (পাহাড়-ছবি, `side`), IconSquare,
  StatusPill, WeekStrip, AvatarStack, ProgressRing, MiniBars, StackedBar, DayBlock, Fab।
- `Avatar` এখন নাম অনুযায়ী একই শান্ত রং (`nameTone`)।
- TopBar-এ `sub` আর `note`; বেশির ভাগ পাতায় ছোট উপ-লাইন যোগ হয়েছে।
