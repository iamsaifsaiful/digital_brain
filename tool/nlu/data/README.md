# শেখানোর ডেটা (ধাপ D)

```
python3 tool/nlu/data/generate.py            # → tool/nlu/out/data/ (একই seed = একই ফাইল)
python3 tool/nlu/data/paraphrase.py prepare  # AI-রূপের অনুরোধ আর খরচের অনুমান; কিছু পাঠায় না
```

| ফাইল | কী |
|---|---|
| `lexicon.py` | নাম, সম্পর্ক, জিনিস-দাম-একক-খাত, একাউন্ট, কাজের ক্রিয়ার রূপ, সম্বন্ধ/অধিকরণ বিভক্তি |
| `render.py` | টাকা, তারিখ, সময়, তালিকার নম্বর, সাল/মাস যেভাবে বলা হয় — শব্দ আর মান একসাথে |
| `fill.py` | ছাঁচ পূরণ: `[ক|খ]` বিকল্প, `{slot:রূপ}` মান; শব্দে BIO লেবেল |
| `templates_*.py` | intent-ওয়ারি ছাঁচ; ফাঁকা লাইনে পরিবার আলাদা; `@op=…` ধরনের লেবেল যেগুলোর শব্দ নেই |
| `noise.py` | আঞ্চলিক রূপ, শুনতে ভুল, ভরাট শব্দ, জোড়া শব্দ, ইংরেজি অঙ্ক, যতিচিহ্ন বাদ |
| `generate.py` | সব মিলিয়ে: কয়েক অনুরোধ, শিরোনাম-তালিকা, প্রসঙ্গ, dedupe, যাচাই-সেটের কাছাকাছি বাদ, পরিবার ধরে train/dev, পরিসংখ্যান, ১,০০০ বাক্যের পর্যালোচনা CSV |
| `paraphrase.py` | Anthropic/Gemini batch দিয়ে নতুন রূপ; ট্যাগ হুবহু না থাকলে বাদ; key শুধু পরিবেশ-চলক থেকে |

এক সারি (`train.jsonl`):
`{"id", "family", "kind", "state", "asked", "shown", "tokens", "tags", "text", "intent": [..], "segs": [{"intent", "start", "end", "slots"}], "noise": [..], "split"}`

মান: তারিখ `2027-06-15` / `????-06-15` (সাল বলা হয়নি) / `rel:1` / `rel:-1` / `wd:শুক্রবার` / `wd:-শুক্রবার` (গত) / `dom:15` / `week:+1` / `month:+1` / `month_end`;
সময় `19:30`, দিনের ভাগ ছাড়া `?07:00`; টাকা পূর্ণসংখ্যা; তালিকা `idx:3`, `idx:-1`, `range:2-4`, `first:2`, `last:3`, `except:1`, `all`, `opt:1`।

যাচাই-সেটের (`tool/nlu/gold/`) কোনো বাক্য বা তার কাছাকাছি রূপ এখানে ঢোকে না — `generate.py` প্রতিবার বাদ দেয় আর `dropped_gold.jsonl`-এ লিখে রাখে।
